# androidTest に H.265 送受信の e2e テストを追加する

- Priority: Low
- Created: 2026-07-13
- Completed:
- Model: DeepSeek V4 Pro
- Branch: feature/add-e2e-h265

## 目的

H.265 (HEVC) コーデックでの映像送受信が行えることを e2e で検証する。sora-js-sdk の `e2e-tests/tests/h265.test.ts` に相当する。

## 優先度根拠

- H.265 はコーデック依存が強く、Gradle Managed Device (エミュレータ) では H.265 エンコードが利用できない可能性が高い。実行には対応 HW を持つ実機が前提となり、CI での常時実行が難しい。
- 上記制約により Low とする。

## 現状

- 既存 e2e は H.265 を検証していない。
- サンプルアプリでは H.265 プロファイル設定を追加済みだが自動テストがない。

## 設計方針

- 映像コーデックを H.265 に設定した送信チャネルと受信チャネルを接続する。
- 映像は `DummyVideoCapturer` で送信する。
- `getStats()` の video `outbound-rtp` / `inbound-rtp` で `bytesSent`/`bytesReceived` が 0 より大きいことを確認する。
- エミュレータで H.265 エンコード非対応の場合はスキップ判定を入れ、対応デバイスでのみ実行する。CI 実行の可否は issue 0060 (e2e CI) の実行環境に依存する。

## 完了条件

- H.265 で送受信し video RTP の疎通を確認する e2e テストが追加されていること。
- H.265 非対応環境ではスキップする判定が入っていること。
- 対応デバイス上で完走すること。
